# SafeRoute AI

SafeRoute AI is an AI-based emergency escape navigation system designed to simulate intelligent evacuation inside a building during fire or other emergency situations.

## Objective

The system will model a building environment and determine safe escape routes while considering dynamic hazards and changing environmental conditions.

## Planned Features

- Building/grid environment simulation
- Pathfinding algorithms
- Multiple emergency exits
- Fire and hazard simulation
- Dynamic obstacles
- Safety-aware route selection
- Dynamic route re-planning
- AI-based emergency reasoning
- Visualization using Pygame
- Algorithm experiments and comparison

## Technology

- Python
- Pygame
- Git
- GitHub
